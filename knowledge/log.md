# Bashkit Knowledge Update Log

## 2026-10-07

* **Fix**: jq input stream follows jq 1.7: `-n` leaves the stream to `input`/`inputs`, `-s` on empty input gives `[]`, each FILE is read separately (`input_filename`, `input_line_number` as jq counts lines), a missing file is reported and skipped (exit 2), a runtime error prints `jq: error (at FILE:LINE): ...` and moves on to the next input, `input` fails with `No more inputs`, `-e` uses the last output, values before a JSON syntax error are processed. Debian-oracle jq score 67.5% to 74.2%.
* **Fix**: awk `for (k in a)` without `PROCINFO["sorted_in"]` now visits keys in gawk's order (integer arrays ascending with other keys first; string keys in gawk's hash-bucket order), so unsorted loops print like Debian awk. All gawk cases in the Debian-oracle awk set now pass (L-AWK-001 narrowed to post-`delete` order).
* **Feature**: awk rewritten to target gawk 5.2 (Debian's `awk`). New lexer, parser, async evaluator, ERE translation with POSIX leftmost-longest matching, gawk number formatting and `printf`, gawk's `rand()` sequence, `substr`/`getline`/`typeof` edge cases, `-f`/`-e`/`--` options and gawk's error messages. `system()`, `print | cmd` and `cmd | getline` now run through the sandbox shell (execution-plan driver). Debian-oracle score for awk went from 51% to 94% of 260 cases; the remaining gawk gap is unsorted `for (k in a)` order (L-AWK-001). All resource caps kept; new TM-DOS-128 for awk commands. See foundations/builtins "awk".
* **Fix**: array literals expand like command words. `arr=(*.txt x{1,2})` now runs brace and pathname expansion (honoring `nullglob`; quoted words stay literal), and `arr=([2]=x y)` sets indexed elements instead of storing `[2]=x`. Under `failglob` an unmatched pattern is stored as-is rather than aborting (WTF in code). `command -v a b ...` reports every name found and fails only if none was. `declare -a d=(...)` is unchanged here (declare/local work is in a separate branch).
* **Decision**: CPython's workload priority is agents running `python3` for scripted logic (processing a file, transforming data). Low-use stdlib modules are no longer shipped: `unittest`, `doctest`, profilers, `compileall`/`zipapp`, `dbm`/`shelve`, `plistlib`, `wave`, `netrc`, `cmd`, `tty`/`pty`, and `bz2`/`lzma`/`compression.zstd` (no C codec in the guest anyway). Stdlib zip 3.58 to 3.16 MB. L-CPY-009 updated. See [CPython WebAssembly Runtime](runtimes/cpython-wasm.md#workload-priority).
* **Feature**: `yes` and `seq` stream into pipelines. As a producer stage they write chunks into the pipe as they go (`Context::stdout_stream`), so `yes | head -1` and `seq 1000000 | head -1` stop after the first chunk with `PIPESTATUS` `141 0` instead of running to the output cap and printing a truncation notice. Step 2 of the roadmap (streaming builtin I/O), starting with the generators.
* **Feature**: `sudo` and `busybox`, the top missing commands in the gap replay (`sudo tee /etc/x <<EOF`, `busybox tar --help`). `sudo` skips its options and runs the command (leading `VAR=VALUE` through `env`, `-s`/`-i` through `bash -c`; `-v`/`-k` succeed, `-l` lists ALL); `busybox APPLET` runs the builtin of that name, `--list` lists them (L-SUDO-001). `nohup`/`nice`/`flock` no longer steal the inner command's `--help`.
* **Feature**: Plain `cat` streams through pipelines. As a stage it writes 4 KiB chunks into the stage pipe and, in a middle stage, reads its input pipe as it goes (new internal `Context::stdin_stream`), so `cat big | head -1` and `while :; do echo; done | cat | head -1` end with SIGPIPE (`141`) like bash instead of running to a limit. `cat` also reports a missing operand and continues with the rest, as GNU cat does. L-PIPE-001 narrowed.
* **Feature**: `grep` and `tr` stream through pipelines. In a pipeline stage they read their input in ~4 KiB pieces (record-aligned for `grep`, UTF-8-aligned for `tr`) and write results as they go, so `while :; do echo y; done | grep y | head -2`, `yes | tr y n | head -1` and `grep . big | head -1` end with SIGPIPE (`141`) like bash instead of running to a limit; `grep -m` stops reading at its budget. Summarizing options (`grep -c/-l/-L/-q`, context, `-b`, `-r`; `tr -s`) stay buffered. L-PIPE-001 narrowed.
* **Fix**: `${x#pat}`/`${x%pat}` follow the glob grammar. A lone `*` matches empty for the short forms (`${x#*}` and `${x%*}` keep `x`; they dropped a character), and patterns with `?` or several `*` (`${x%?}`, `${p#*/*/}`, `${p##*.*.}`) now match instead of being compared as literal text. Single-`*` patterns keep their linear fast path.
* **Fix**: `set -e` follows bash's ignored contexts. `! cmd` no longer exits. A function or subshell run as an `if`/`while` condition or a non-final `&&`/`||` element keeps going after a failing command inside (`if f; then`, `check bad && x`, `( false; echo ) || y`). `$( )` drops `-e` unless `shopt -s inherit_errexit`, and with it stops at the first failure. Debian-oracle cases `errexit-exceptions`, `errexit-subshell-and-cmdsub` and `errexit-in-function-called-from-and` now match bash. See foundations/architecture "`set -e` contexts".
* **Fix**: Quoted or escaped glob characters are literal everywhere. `echo a\*`, `a"*"` and `a'?'` no longer glob; `case`/`[[ == ]]` patterns match `"$x"`, `'a*'`, `a\*` and `\[s\]` literally; `"*"zz*` with no match prints `*zz*` (escapes no longer leak); `"$x"zz*` no longer reads `$xzz`; `'a'$x` expands and `'a'*` globs; `a{1,2}"*"` still brace-expands. The lexer escapes quoted glob characters in mixed words (the existing `QuotedGlobWord` convention, now with quote markers); `expand_word` returns unescaped text for non-glob uses; patterns use `expand_pattern_word`. Known gap: data from an unquoted expansion inside such a word loses `\` before glob characters when nothing matches.
* **Fix**: Redirect and heredoc gaps from the Debian-oracle cases. A function call's redirected output no longer also streams to the caller (`f > out` printed `out` under `exec_streaming` and the CLI; `f 2>/dev/null` leaked stderr). `&>> file` parses (as `>> file 2>&1`). Heredocs: several per line (`cat <<A <<B` uses the last), `N<<EOF` on a numbered fd (was the word `3`), and words or redirects after the delimiter (`cat <<A file`, `done <<A 3<<B >out`). `paste - -` shares stdin between its `-` operands like GNU.
* **Feature**: `fmt` builtin, on the uutils `fmt` engine (MIT, vendored: Knuth-Plass line breaking, paragraphs, `-c`/`-t`/`-s`/`-u`/`-p`, `-w`/`-g`, `-WIDTH`). Spec: `fmt.test.sh`. See foundations/builtins "fmt".

* **Fix**: `exec >log 2>&1` (and `exec 2>/dev/null`, `exec >>log`) redirects the script's own output. It used to be recorded in the fd table but only consulted by `>&N`, so everything still printed. fd 1/2 entries now route each top-level command's output (`route_exec_output`) and pause streaming for those streams. `exec 3>&1 >log; echo x >&3` reaches the caller through a passthrough, `exec 1>&3` restores, and `$( )`/pipelines keep their own stdout (`$(cmd 2>&1)` still captures). A failed `exec >/bad/path` leaves fd 1 alone with status 1. L-PROC-001 updated.
* **Fix**: `$'\x1e'` and `$'\x1f'` bytes (record/unit separators) are kept as data. Found while bounding `make` recursion.

* **Feature**: Pipelines stream. Pending calls remain outside snapshots by design. TM-DOS-098 records bounded-channel, existing-limit, and owned-session retention controls. Recorded in [Builtin Commands](foundations/builtins.md), [Architecture](foundations/architecture.md), [Snapshot History and Deltas](foundations/snapshot-history.md), and the [Threat Model](security/threat-model.md).
* **Security**: Extended [Request Execution Lifecycle](security/request-lifecycle.md) and TM-ISO-027 with one revocable lease per `exec*()` across extension values, custom/host builtin VFS views, and tool-callback request context. The shared budget closes request work; the lease revokes retained facility handles deterministically. Cleanup is bounded, idempotent, and exposes only sanitized status/counts. Intentional session-lived host VFS access now requires `BuiltinRegistry::insert_trusted`. Updated [Builtin Commands](foundations/builtins.md) and [Threat Model](security/threat-model.md).
* **Decision**: Replaced the bespoke dotted-path `yaml` helper with feature-gated `yq`. YAML/JSON conversion surrounds the existing jq/jaq evaluator, so nested selection, iteration, `select`, `map`, construction, and assignment use one query language and one execution-limit boundary. Safe in-place updates use sibling-temp write plus rename. Mapping keys sort deterministically at the existing JSON-value boundary so `yq` does not globally alter serde_json ordering for other builtins. mikefarah/yq-only node/style operators and non-JSON conversions remain explicit limitations in [Known Limitations](operations/limitations.md); parser/output controls are recorded as TM-DOS-101 in the [Threat Model](security/threat-model.md).
* **Security**: Hardened TM-INF-018: `date` now defaults to UTC and resolves timezone rules only from sandbox `TZ` through bundled IANA data. Invalid, unsupported, and path-style values fail closed to UTC; naive `-d` parsing and DST transitions share the selected zone, while explicit offsets remain authoritative. `touch -t` also interprets naive stamps as UTC so a later `date -r` cannot expose host-local conversion. Clock virtualization remains independent of timezone selection. The supported boundary and POSIX-rule limitation are recorded in [Known Limitations](operations/limitations.md).
* **Security**: Added TM-DOS-103 and budget-aware owning builders for strings, vectors, and byte streams. Archive/compression growth now charges the shared live-byte budget before reserve/extend; overflow and concurrent overcommit fail closed, while allocation/producer errors and drop release their leases.
* **Contract**: Added a canonical, generated [Public Capability Parity](status/capability-parity.md) matrix across Rust `BashBuilder`/`BashTool`/`ScriptedTool`, CLI, Python, NAPI JavaScript, browser WASM, and C ABI. Every supported cell names executable evidence; every intentional exclusion states why. The central drift check rejects missing cells and stale test selectors.
* **Security**: Added TM-ISO-025 for wrapper rebuilds silently dropping host configuration. The first audit finding was NAPI `reset()` losing constructor-seeded VFS files; shared state now retains and restores them, with a regression test.
* **Testing**: Added a quarterly competitor-regression corpus contract: immutable upstream provenance, explicit pass/bug/intentional-divergence classification, real-Bash or locked oracles, and a feature-complete hermetic CI lane. The first import covers eleven behavior fixes from `vercel-labs/just-bash` between 2026-05-05 and 2026-08-05; it exposed and fixes tar old-style option bundles, while the ordered curl-data fix is supplied by its dedicated PR.
* **Threat**: Registered TM-INF-032 for executing imported third-party behavior fixtures. Imports remain manually reviewed checked-in JSON, CI never fetches upstream content, and only explicitly marked portable cases reach the host-Bash oracle.
* **Decision**: Made `StreamData` the authoritative byte transport for execution stdin, pipelines, redirects, results, callbacks, and native bindings. Text decoding is confined to shell/parser/text-builtin/JSON boundaries; command substitution removes NUL because Bash variables cannot contain it. Updated [Architecture](foundations/architecture.md), [Known Limitations](operations/limitations.md), and [Threat Model](security/threat-model.md).
* **Testing**: Added byte-for-byte Bash differential and regressions for binary base64/head/cat pipelines, mixed UTF-8 and invalid bytes, redirects, output caps, callbacks, custom builtins, command substitution, and C/Python/Node binding results.
* **Bindings**: Brought `@everruns/bashkit-wasm` to native-binding parity for the browser-critical surface: Gatekeeper `analyze()`, sticky cooperative cancellation, streaming stdout/stderr, content-addressed `commit()`/`checkout()`, and binary-safe VFS helpers. Contract and verification live in [Browser Package](runtimes/browser-package.md).
* **Limitation removed**: L-WASM-001 is lifted. A JS host timer bridge now powers `sleep`, builtin and execution deadlines, and tool `timeoutMs` without threads or cross-origin isolation. Synchronous CPU work remains bounded by deterministic resource limits because the event loop cannot deliver timers or cancellation until execution yields.
* **Threats**: TM-DOS-057 is fully mitigated now that JS-host wasm shares the portable execution deadline; TM-INF-028 now covers wasm output and custom-builtin callbacks, whose errors are message-only, path-stripped, and capped before crossing the sandbox boundary.

## 2026-08-01

* **Decision**: Split the rollout across two releases, reader first as a patch (0.14.5), writer and public API next as a minor (0.15.0). `min_reader` makes every *future* format change safe but cannot make the first one safe: readers that predate it fail on a v2 container with a JSON parse error naming neither version nor format. A release that reads v2 without writing it gives deployments a rollback target before anything can produce v2. Recorded in [Snapshot History and Deltas](foundations/snapshot-history.md).
* **Decision**: The reader release adds no public API, so it ships as a patch, new types `pub(crate)`, and the version refusal reuses `Error::Internal` because `Error` is not `#[non_exhaustive]` and a new variant would be breaking. Its v2 encoder is reachable only from tests: a decoder cannot be tested without something that produces valid input for it.
* **Constraint**: `CheckoutPolicy::Superset` makes builtin *removal* the breaking direction, removing or renaming one breaks restores of every snapshot written before the removal. Additions are safe by construction; nothing in the release process flags a removal.
* **Testing**: Added hostile-input coverage for the object graph, a libFuzzer target over both format paths, decode/id/graph-walk property tests, and integration tests establishing that forged VFS paths (traversal, non-normalized, relative, empty) are *unreachable* rather than rejected. That invariant depends on restore not normalizing paths; if it ever does, `/a/../b.txt` resolves and the containment is gone.

## 2026-07-30

* **Bindings**: Exposed `commit`/`checkout`/`capabilities` and the `SnapshotGraph` queries to Python and JS. Object stores cross as `dict[str, bytes]` / `Record<string, Buffer>` keyed by hex id, and `CheckoutPolicy` as a case-insensitive string, so hosts drop them straight into a database column. Runnable example in `crates/bashkit-python/examples/session_history.py`.
* **Performance**: Added a compressibility probe before deflating an object. Deflating incompressible chunks (a large binary file's content) and discarding every result dominated commit time; a 64 MB file went from 2 439 ms to 1 003 ms with byte-identical output. Commit also encodes storage blobs without materializing `[kind][payload]` first, removing one full copy of each chunk.
* **Measurement**: Recorded large-binary behavior in `crates/bashkit/benches/results/`, chunking holds up (a 16-byte edit in a 64 MB file costs 152 KB), but peak RSS is ~5x file size and the per-edit floor is the flat file manifest at ~2 KB per MB. Both recorded as known gaps.
* **Implementation**: Shipped the snapshot object graph in `crates/bashkit/src/snapshot/`, content-addressed chunks/files/trees/shell/caps/commits, `Bash::commit`/`Bash::checkout`, `SnapshotGraph` (parents, ancestry, diff, plan_checkout, reachable), and a versioned binary container. `snapshot()` now emits a packed commit; v1 JSON payloads stay readable and are covered by a golden fixture corpus.
* **Decision**: `CheckoutPolicy::Superset` is the default, not `Strict` as proposed. The fingerprint records the whole builtin set, so `Strict` by default would break every stored snapshot the moment bashkit adds a builtin, pushing callers to `Force` and losing the check. Recorded in [Snapshot History and Deltas](foundations/snapshot-history.md).
* **Decision**: Content-defined chunking is in-tree (gear hash, pinned constants) rather than the `fastcdc` crate, the proposal's fallback, taken up front since the parameters are format constants regardless.
* **Enforcement**: Object identity covers decoded content, not compressed framing, so hosts may recompress freely; bytes appended after a deflate stream are now rejected rather than silently ignored.
* **Threats**: Registered TM-SNAP-002 through TM-SNAP-006 in [Threat Model](security/threat-model.md).

* **Creation**: Added [Snapshot History and Deltas](foundations/snapshot-history.md) (`Status: Proposed`) in response to [#2221](https://github.com/everruns/bashkit/issues/2221), a content-addressed object graph with a commit DAG for forks, content-defined chunking for binary-safe per-file differentials, a two-phase pull API instead of a host store trait, three-number version rules backed by a golden fixture corpus, and a capability fingerprint gating restore.
* **Decision**: Recorded the rejected alternative, byte-delta patch chains (bsdiff/xdelta/`zstd --patch-from`), and why the graph model wins for the branch-and-truncate read pattern.
